# 📊 DataCo Supply Chain — End-to-End Data Analysis

An end-to-end **Data Analytics project** analyzing supply chain data to uncover insights related to sales, profit, orders, customers, products, regions, payment methods, and delivery performance.

This project demonstrates the complete analytics workflow using **Excel, Python, SQL, and Power BI**.

---

## 📌 Project Overview

The objective of this project was to transform raw supply chain data into meaningful business insights through data cleaning, exploratory analysis, SQL-based business analysis, and interactive Power BI reporting.

The project covers:

* Data cleaning and preparation
* Exploratory Data Analysis
* SQL business analysis
* Sales and profit analysis
* Regional and category analysis
* Order and delivery analysis
* KPI development
* Interactive Power BI reporting
* Business insights and recommendations

---
